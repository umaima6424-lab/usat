Key Mathematics formulas

A short formula sheet for quick revision. See the full USAT formulas page.

Algebra

  • x = [−b ± √(b² − 4ac)] / 2a
  • Sum of roots = −b/a
  • Product of roots = c/a
  • (a ± b)² = a² ± 2ab + b²
  • a² − b² = (a − b)(a + b)

Logarithms & Exponents

  • log(ab) = log a + log b
  • log(a/b) = log a − log b
  • log aⁿ = n log a
  • aᵐ · aⁿ = aᵐ⁺ⁿ

Sequences & Series

  • AP: aₙ = a + (n − 1)d
  • AP: Sₙ = n/2 [2a + (n − 1)d]
  • GP: aₙ = arⁿ⁻¹
  • GP: Sₙ = a(1 − rⁿ)/(1 − r)
  • Infinite GP: S = a/(1 − r), |r| < 1

Trigonometry

  • sin²θ + cos²θ = 1
  • sin 2θ = 2 sin θ cos θ
  • cos 2θ = cos²θ − sin²θ
  • sin(A ± B) = sinA cosB ± cosA sinB
  • Law of sines: a/sinA = b/sinB = c/sinC

Coordinate Geometry

  • Distance = √[(x₂−x₁)² + (y₂−y₁)²]
  • Slope m = (y₂−y₁)/(x₂−x₁)
  • y − y₁ = m(x − x₁)
  • Circle: (x − h)² + (y − k)² = r²

Differentiation

  • d/dx (xⁿ) = nxⁿ⁻¹
  • d/dx (sin x) = cos x
  • d/dx (eˣ) = eˣ
  • Product: (uv)′ = u′v + uv′
  • Chain: dy/dx = dy/du · du/dx

Integration

  • ∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C
  • ∫ eˣ dx = eˣ + C
  • ∫ cos x dx = sin x + C
  • ∫ 1/x dx = ln|x| + C

Permutation, Combination & Probability

  • ⁿPᵣ = n!/(n − r)!
  • ⁿCᵣ = n!/[r!(n − r)!]
  • P(E) = favourable / total
  • Vectors: a·b = ab cos θ
Preparation tips

How to prepare USAT Mathematics

  • Strengthen algebra, trigonometric identities and differentiation rules. These appear everywhere.
  • Practise integration, sequences and coordinate geometry with timed sets.
  • Solve each problem on paper. Do not rely on mental shortcuts for long steps.

Published guides list differentiation and integration among the topics, so practise basic rules and standard integrals.
