Key Computer Science formulas

A short formula sheet for quick revision. See the full USAT formulas page.

Number Systems

  • Binary base 2, Octal base 8, Hex base 16
  • Decimal → binary: divide by 2, read remainders upward
  • Two's complement = invert bits + 1
  • 1 byte = 8 bits, 1 KB = 1024 bytes

Boolean Algebra

  • A + A′ = 1, A · A′ = 0
  • De Morgan: (A·B)′ = A′ + B′
  • De Morgan: (A + B)′ = A′ · B′
  • NAND and NOR are universal gates

Programming & Algorithms

  • Array index starts at 0
  • Binary search: O(log n), needs sorted data
  • Linear search: O(n), bubble sort: O(n²)
  • Stack = LIFO, Queue = FIFO
Preparation tips

How to prepare USAT Computer Science

  • Practise number system conversions and Boolean algebra until they are automatic.
  • Read short C++ or Python snippets and predict the output.
  • Revise operating system, network and database basics as definition MCQs.
