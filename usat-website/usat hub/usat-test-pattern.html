USAT Test Pattern 2026: Marks, Sections and Time

Public USAT guides describe a 100-mark test: 75 MCQ marks and a 25-mark descriptive part. Patterns can change, so confirm every detail with the official HEC notice before test day. This page explains each section and how to plan your time.

Time plan

How to manage your time

MCQ section

With about 100 minutes for 75 MCQs, aim for roughly 80 seconds per question. Answer the easy ones first and mark hard ones to revisit.

No negative marking

Published guides report no negative marking. Never leave a question blank. Remove two options and choose.

Essay

Spend 5 minutes planning, 30 minutes writing and 5 minutes checking. Write clearly and stay on topic.

Questions

USAT test pattern FAQs

What is the USAT test pattern?

Public guides describe 75 MCQs worth 75 marks, made of Verbal Reasoning (20), Quantitative Reasoning (25) and a Subject section (30), plus a 25-mark descriptive essay part, for 100 marks in total. Patterns can change, so confirm with HEC before test day.

Is there negative marking in the USAT?

Published guides state that there is no negative marking, so attempt every question. Check the latest HEC instructions to be sure.

What is the qualifying score?

Guides report a qualifying score of 50 out of 100. Universities may set higher merit requirements for competitive programmes, so check each university's admission policy.
